# SMS Spam Detection

A leakage-free, reproducible baseline that classifies SMS text messages as spam or ham.

## Dataset

[SMS Spam Collection](https://archive.ics.uci.edu/dataset/228/sms+spam+collection), stored as `data/spam.csv`
(`v1` = label `ham`/`spam`, `v2` = message text). These are short SMS text messages, not any other kind of
message; see [Limitations](#limitations).

Some messages contain escaped quotes that broke the CSV quoting, so their text spilled into three unnamed
extra columns. The notebook joins those fragments back into the message before dropping the extra columns,
then removes exact duplicate rows.

## Method

- **Preprocessing** (stateless, applied per message): lowercase, tokenize, keep alphanumeric tokens, Porter stem.
  Stopword removal is tested as an explicit experiment and kept only if it improves cross-validated PR-AUC.
- **Split first**: a stratified train/test split with a fixed random state. The test set is used once, at the end.
- **Pipeline**: `TfidfVectorizer -> classifier` inside an sklearn `Pipeline`, so TF-IDF is fit only on training
  folds and never sees test data.
- **Models**: the original eleven classifiers (SVC, KNN, Naive Bayes, Decision Tree, Logistic Regression,
  Random Forest, AdaBoost, Bagging, Extra Trees, Gradient Boosting, XGBoost) with their original parameters.
- **Evaluation**: stratified k-fold cross-validation on the training set, reporting accuracy, precision, recall,
  F1 and PR-AUC (average precision) as mean and standard deviation.
- **Pre-registered selection rule**: highest mean CV PR-AUC; near-ties broken by higher mean CV recall.
- **Threshold**: the lowest threshold whose out-of-fold precision on the training set meets the target;
  the test set is reported at both the default and the tuned threshold.

## How to run

From the repository root:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python -m ipykernel install --user --name sms-spam --display-name "Python (sms-spam)"

jupyter nbconvert --to notebook --execute --inplace notebooks/01_sms_spam_baseline.ipynb
python scripts/make_readme.py        # regenerate the Results section from results/
python scripts/check_consistency.py  # fails if README and results/ disagree
```

The notebook writes `results/cv_results.csv`, `results/metrics.json` (the single source of truth for every
number above) and `models/spam_pipeline.joblib` (not committed).

## Limitations

- SMS only: the data is SMS text messages, **not email**. There are no subject lines, headers, HTML or long
  bodies, and the model has not been tested on email at all.
- English only, and the collection is old, so current spam styles are not represented.
- One raw record appears to be two messages merged by a stray line break inside a quoted field; it is kept as-is.
- The saved pipeline expects text that has already been through the notebook's `transform_text` preprocessing.
